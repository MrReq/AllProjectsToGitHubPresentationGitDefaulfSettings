# Unreal Engine

## 1. Czym jest Unreal Engine?

Unreal Engine jest silnikiem do tworzenia gier komputerowych oraz zaawansowanych aplikacji 3D.

Unreal Engine jest rozwijany przez firmę Epic Games.

Silnik pozwala tworzyć między innymi gry 2D i 3D, aplikacje VR i AR, symulacje, wizualizacje architektoniczne oraz interaktywne środowiska.

Unreal Engine jest szczególnie znany z zaawansowanej grafiki 3D, systemów oświetlenia, fizyki oraz narzędzi do tworzenia dużych światów.

## 2. Unreal Engine a języki programowania

Unreal Engine wykorzystuje przede wszystkim język **C++**.

C++ pozwala tworzyć bardziej zaawansowaną logikę aplikacji i gier.

Unreal Engine posiada również system **Blueprints**, który pozwala tworzyć logikę za pomocą wizualnych elementów połączonych ze sobą w grafie.

Dzięki Blueprints można tworzyć wiele mechanizmów gry bez konieczności pisania całego kodu C++.

## 3. Unreal Editor

**Unreal Editor** jest środowiskiem graficznym służącym do tworzenia projektów Unreal Engine.

Pozwala między innymi tworzyć poziomy, dodawać obiekty, konfigurować materiały, światła, kamery oraz testować grę.

Najważniejsze elementy edytora obejmują między innymi:

```text
Viewport
Outliner
Details
Content Browser
World Settings
Output Log
```

## 6. Actor

**Actor** jest jednym z podstawowych elementów Unreal Engine.

Actor reprezentuje obiekt, który może zostać umieszczony w świecie gry.

Przykładami Actorów mogą być:

```text
Player
Enemy
Weapon
Vehicle
Light
Camera
Door
Trigger
```

Actor może posiadać komponenty określające jego właściwości i zachowanie.

## 7. Components

Komponenty pozwalają dodawać funkcjonalności do Actorów.

Przykładowe komponenty to:

```text
Static Mesh Component
Skeletal Mesh Component
Camera Component
Audio Component
Collision Component
Movement Component
```

Dzięki komponentom można budować bardziej złożone obiekty z mniejszych elementów.

## 8. Pawn

**Pawn** jest specjalnym typem Actora, który może być kontrolowany przez użytkownika lub AI.

Pawn reprezentuje między innymi ciało lub obiekt sterowany w świecie gry.

Może być wykorzystany jako podstawa dla gracza, pojazdu albo innej kontrolowanej jednostki.

## 9. Character

**Character** jest specjalizowanym typem Pawna przeznaczonym przede wszystkim do reprezentowania postaci.

Posiada gotowe mechanizmy związane z poruszaniem się postaci.

Character jest często wykorzystywany jako baza dla głównego bohatera gry.

Przykładowa hierarchia może wyglądać tak:

```text
Actor
  ↓
Pawn
  ↓
Character
```

## 10. Controller

Controller odpowiada za sterowanie Pawnem.

Można wyróżnić między innymi:

```text
PlayerController
AIController
```

`PlayerController` obsługuje sterowanie związane z graczem.

`AIController` może sterować Pawnem za pomocą sztucznej inteligencji.

Może definiować między innymi:

HUD
Rules

Przykładowo GameMode może określać, jaka postać zostanie utworzona dla gracza po rozpoczęciu rozgrywki.

## 14. Blueprint

**Blueprints** są wizualnym systemem programowania Unreal Engine.

Zamiast pisać kod, programista może tworzyć graf złożony z węzłów.

Przykładowy schemat może wyglądać tak:

```text
Event BeginPlay
       ↓
   Delay
       ↓
 Print String
```

Blueprint może wykonywać logikę gry, obsługiwać zdarzenia, sterować obiektami oraz reagować na interakcje gracza.

## 15. Blueprint Class

**Blueprint Class** jest klasą tworzoną za pomocą systemu Blueprint.

Może być wykorzystana jako podstawa dla konkretnego obiektu gry.

Przykładowo można stworzyć:

```text
BP_Player
BP_Enemy
BP_Door
BP_Weapon
BP_Vehicle
```

Blueprint może posiadać własne komponenty, zmienne, funkcje oraz zdarzenia.

## 16. C++ w Unreal Engine

Unreal Engine pozwala tworzyć własne klasy C++.

Klasy Unreal Engine często wykorzystują makra oraz system refleksji silnika.

Przykładowa klasa może wyglądać następująco:

```cpp
UCLASS()
class AMyCharacter : public ACharacter
{
    GENERATED_BODY()
};
```

`UCLASS()` informuje system Unreal Engine, że dana klasa jest klasą zarządzaną przez system refleksji Unreal.

## 17. UObject

`UObject` jest podstawową klasą wielu elementów systemu Unreal Engine.

Wiele klas Unreal Engine dziedziczy bezpośrednio lub pośrednio po `UObject`.

System `UObject` zapewnia między innymi obsługę refleksji, właściwości silnika oraz zarządzanie pamięcią przez **Garbage Collector**.

## 18. UPROPERTY

`UPROPERTY()` jest makrem używanym do oznaczania właściwości C++ obsługiwanych przez system Unreal Engine.

Przykład:

```cpp
UPROPERTY(EditAnywhere)
float Health;
```

Dzięki odpowiednim specyfikatorom właściwość może być między innymi dostępna w Unreal Editor.

## 19. UFUNCTION

`UFUNCTION()` jest makrem pozwalającym oznaczyć funkcję jako funkcję obsługiwaną przez system Unreal Engine.

Przykład:

```cpp
UFUNCTION()
void TakeDamage();
```

Funkcje mogą być również dostępne z poziomu Blueprintów, jeżeli zostaną odpowiednio oznaczone.

## 20. Reflection System

Unreal Engine posiada system refleksji pozwalający silnikowi znać informacje o klasach, właściwościach i funkcjach.

System ten jest wykorzystywany między innymi przez:

```text
Blueprints
Editor
Serialization
Networking
Garbage Collection
```

Makra takie jak `UCLASS`, `UPROPERTY` oraz `UFUNCTION` są częścią tego systemu.

## 21. Garbage Collection

Unreal Engine posiada system automatycznego zarządzania pamięcią dla obiektów opartych na `UObject`.

System Garbage Collection wyszukuje obiekty, które nie są już używane, i może zwolnić zajmowaną przez nie pamięć.

Dzięki temu programista nie musi ręcznie zarządzać pamięcią wszystkich obiektów Unreal Engine.

## 40. Behavior Tree

**Behavior Tree** pozwala definiować zachowanie sztucznej inteligencji.

Przykładowy przeciwnik może wykonywać:

```text
Patrol
   ↓
Detect Player
   ↓
Chase Player
   ↓
Attack Player
   ↓
Return to Patrol
```

Behavior Tree pozwala tworzyć bardziej złożone zachowania bez pisania całej logiki w tradycyjnym kodzie.

## 41. Blackboard

## 42. Navigation System

Navigation System pozwala AI poruszać się po świecie gry.

System wykorzystuje między innymi **NavMesh**, czyli obszar określający przestrzeń, po której AI może się poruszać.

Przykładowo przeciwnik może znaleźć drogę do gracza omijając przeszkody.

## 43. World Partition

**World Partition** jest systemem przeznaczonym do zarządzania dużymi światami gry.

Pozwala dzielić świat na mniejsze fragmenty i ładować odpowiednie części zależnie od potrzeb.

Jest szczególnie przydatny podczas tworzenia dużych, otwartych światów.

## 50. Unreal Engine a Unity

Unreal Engine i Unity są silnikami wykorzystywanymi do tworzenia gier i aplikacji 3D.

Unreal Engine jest silnie związany z C++ oraz systemem Blueprints.

Unity wykorzystuje przede wszystkim C#.

Unreal Engine posiada bardzo rozbudowane narzędzia do tworzenia zaawansowanej grafiki 3D.

Unity jest również szeroko wykorzystywane w grach, aplikacjach mobilnych, VR, AR oraz innych projektach interaktywnych.

Oba silniki posiadają systemy komponentów, fizyki, animacji, materiałów, audio oraz interfejsów użytkownika.
