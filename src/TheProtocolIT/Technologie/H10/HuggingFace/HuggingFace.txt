# Hugging Face

## 1. Czym jest Hugging Face?

**Hugging Face** to platforma oraz ekosystem narzędzi związanych przede wszystkim ze **sztuczną inteligencją, uczeniem maszynowym i generatywną AI**.

Hugging Face jest szczególnie znane z udostępniania **modeli AI, datasetów oraz bibliotek umożliwiających ich trenowanie, uruchamianie i wdrażanie**.

Platforma jest bardzo popularna w obszarze **NLP, LLM, Computer Vision, Audio oraz Multimodal AI**.

Można ją traktować jako swego rodzaju **GitHub dla modeli AI i datasetów**, chociaż Hugging Face oferuje znacznie więcej funkcji niż samo przechowywanie plików.

Oficjalna strona platformy to **huggingface.co**.

## 2. Do czego służy Hugging Face?

Hugging Face pozwala między innymi:

- wyszukiwać gotowe modele AI,
- pobierać modele i uruchamiać je lokalnie,
- trenować własne modele,
- dostrajać istniejące modele,
- przechowywać modele,
- przechowywać datasety,
- testować modele,
- tworzyć aplikacje AI,
- udostępniać modele innym użytkownikom,
- korzystać z modeli przez API,
- tworzyć dema AI,
- wdrażać modele w aplikacjach.

Przykładowo możemy znaleźć gotowy model do:

```text
tłumaczenia
analizy sentymentu
generowania tekstu
klasyfikacji tekstu
rozpoznawania obrazów
generowania obrazów
rozpoznawania mowy
syntezy mowy
odpowiadania na pytania
streszczania tekstu
```

## 3. Historia Hugging Face

Hugging Face powstało w 2016 roku.

Początkowo firma koncentrowała się na technologii związanej z chatbotami.

Z czasem projekt przekształcił się w szeroki ekosystem open-source dla machine learningu.

Jednym z najważniejszych momentów w rozwoju Hugging Face było stworzenie biblioteki **Transformers**.

Transformers stała się jednym z najpopularniejszych narzędzi do pracy z nowoczesnymi modelami AI.

Obecnie Hugging Face jest jednym z najważniejszych miejsc w ekosystemie open-source AI.

## 7. Transformers

Jedną z najważniejszych bibliotek Hugging Face jest:

```text

```

Biblioteka pozwala korzystać z ogromnej liczby gotowych modeli.

Obsługuje między innymi modele oparte na architekturze Transformer.

Przykładowy kod:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")

```

Pipeline automatycznie zajmuje się wieloma szczegółami związanymi z przygotowaniem danych i uruchomieniem modelu.

## 8. Pipeline

`pipeline()` jest jednym z najprostszych sposobów korzystania z modeli Hugging Face.

Przykład analizy sentymentu:

```python

print(classifier("This product is fantastic!"))
```

Możemy również stworzyć pipeline do innych zadań.

Na przykład:

```python

```

albo:


```python

```

Pipeline pozwala szybko rozpocząć pracę bez konieczności ręcznego implementowania całego procesu inferencji.

## 9. Tokenizer

Modele językowe nie otrzymują bezpośrednio zwykłego tekstu.

Tekst jest najpierw przekształcany w **tokeny**.

Proces wygląda mniej więcej tak:

```text
Tekst
   ↓
Tokenizer
   ↓
Tokeny
   ↓
ID tokenów
   ↓
Model
   ↓
Wynik
```

Przykładowo zdanie:

```text
Hello, how are you?
```

może zostać podzielone na tokeny.

Tokenizer następnie zamienia je na identyfikatory liczbowe.

## 10. Przykład Tokenizera

Możemy użyć:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "bert-base-uncased"
)

tokens = tokenizer(
    "Hello world!"
)

print(tokens)
```

Tokenizer może zwrócić między innymi:

```text
input_ids
attention_mask
```

## 11. AutoTokenizer

`AutoTokenizer` automatycznie dobiera odpowiedni tokenizer do wybranego modelu.

Przykład:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "bert-base-uncased"
)
```

Nie musimy ręcznie określać konkretnej klasy tokenizera.

## 18. Fine-tuning

Jedną z ważnych funkcji ekosystemu Hugging Face jest **fine-tuning**.

Fine-tuning polega na dostosowaniu wcześniej wytrenowanego modelu do konkretnego zadania lub domeny.

Przykładowo możemy mieć ogólny model językowy.

Następnie możemy dostroić go do:

```text

rolnictwa

```

Schemat:

```text
Pretrained Model
       ↓
   Fine-tuning
       ↓
Model specjalizowany
```

## 19. Pre-trained model

Model pre-trained został wcześniej wytrenowany na dużej ilości danych.

Nie musimy trenować go od zera.

Możemy pobrać gotowy model i wykorzystać go jako punkt wyjścia.

To ogromna zaleta, ponieważ trening dużego modelu od zera może wymagać ogromnej ilości danych, czasu i mocy obliczeniowej.

## 20. Transfer Learning

```text

        ↓
```

## 22. Gradio

Gradio jest często wykorzystywane razem z Hugging Face.

Pozwala szybko stworzyć interfejs dla modelu AI.

Przykład:

```python
import gradio as gr

def predict(text):
    return text.upper()

demo = gr.Interface(
    fn=predict,
    inputs="text",
    outputs="text"
)

demo.launch()
```

Możemy dzięki temu stworzyć prosty interfejs bez budowania całego frontendu od zera.

## 47. Wady Hugging Face

Nie wszystkie modele są wysokiej jakości.

Nie każdy model nadaje się do zastosowań produkcyjnych.

Niektóre modele wymagają bardzo dużej ilości RAM lub VRAM.

Konfiguracja środowiska AI może być skomplikowana.

Niektóre modele mają ograniczenia licencyjne.

Jakość modelu zależy od danych treningowych.

Modele mogą generować błędne informacje.

W przypadku LLM należy również uwzględniać problem halucynacji.

W takim rozwiązaniu Hugging Face może dostarczać model embeddingowy oraz model językowy.

## 50. Najważniejsze pojęcia do zapamiętania

**Hugging Face** – platforma i ekosystem narzędzi dla AI i machine learningu.

**Hugging Face Hub** – platforma przechowywania i udostępniania modeli, datasetów i aplikacji.

**Transformers** – jedna z najważniejszych bibliotek Hugging Face do pracy z modelami Transformer.

**Pipeline** – prosty interfejs umożliwiający wykorzystanie modeli do określonych zadań.

**Tokenizer** – konwertuje tekst na tokeny i identyfikatory używane przez model.

**Model** – wytrenowany algorytm wykonujący określone zadania AI.

**Dataset** – zbiór danych wykorzystywany do trenowania, dostrajania lub testowania modeli.

**Fine-tuning** – dostosowanie istniejącego modelu do konkretnego zadania.

**Pre-trained model** – model wcześniej wytrenowany na dużej ilości danych.

**Model Card** – dokumentacja modelu.

**Dataset Card** – dokumentacja datasetu.

**Spaces** – środowisko publikowania interaktywnych aplikacji AI.

**Gradio** – biblioteka umożliwiająca szybkie tworzenie interfejsów dla modeli AI.

**Embedding** – reprezentacja danych w postaci wektora liczb.

**Quantization** – zmniejszenie precyzji reprezentacji modelu w celu ograniczenia zużycia pamięci i przyspieszenia działania.

**Inference** – proces wykonywania predykcji przez wytrenowany model.

**LLM** – Large Language Model, czyli duży model językowy.

**RAG** – Retrieval-Augmented Generation, czyli generowanie odpowiedzi z wykorzystaniem dodatkowo wyszukanych informacji.

```text
Hugging Face Hub
       ↓
Models

Transformers
       ↓
Tokenizer

Pipeline

Inference

Fine-tuning

Datasets
```

## 52. Hugging Face w jednym zdaniu

**Hugging Face to jeden z najważniejszych ekosystemów współczesnej AI, który umożliwia wyszukiwanie, pobieranie, trenowanie, dostrajanie, uruchamianie, udostępnianie i wdrażanie modeli oraz datasetów związanych między innymi z LLM, NLP, Computer Vision i multimodalną sztuczną inteligencją.**
