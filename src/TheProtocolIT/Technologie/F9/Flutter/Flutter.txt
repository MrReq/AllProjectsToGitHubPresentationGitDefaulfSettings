# Flutter

## Czym jest Flutter?

Flutter to **open-source'owy framework UI firmy Google** służący do tworzenia aplikacji wieloplatformowych.

Flutter wykorzystuje przede wszystkim język programowania **Dart**.

Największą zaletą Fluttera jest możliwość tworzenia aplikacji na wiele platform przy wykorzystaniu jednej bazy kodu.

Możemy tworzyć między innymi aplikacje na:

Android.

iOS.

Windows.

macOS.

Linux.

Web.

Można więc napisać dużą część aplikacji raz, a następnie uruchamiać ją na różnych platformach.

## Do czego służy Flutter?

Flutter służy przede wszystkim do tworzenia:

aplikacji mobilnych.

aplikacji webowych.

aplikacji desktopowych.

aplikacji biznesowych.

aplikacji e-commerce.

aplikacji społecznościowych.

aplikacji wykorzystujących API.

aplikacji wykorzystujących Firebase.

prototypów i MVP.

## Pierwsza aplikacja Flutter

Minimalna aplikacja Flutter może wyglądać tak:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(
          child: Text('Hello World!'),
        ),
      ),
    );
  }

```

Aplikacja uruchamia funkcję:

```dart

```

która rozpoczyna działanie aplikacji Flutter.

## StatelessWidget

**StatelessWidget** reprezentuje widget, którego stan nie zmienia się podczas jego działania.

Przykład:

```dart
class Welcome extends StatelessWidget {
  const Welcome({super.key});

  @override
  Widget build(BuildContext context) {
    return const Text(
      'Welcome!',
    );
  }
}
```

Jeżeli widget nie musi samodzielnie przechowywać zmiennego stanu, możemy wykorzystać `StatelessWidget`.

## StatefulWidget

**StatefulWidget** jest wykorzystywany wtedy, gdy widget posiada zmieniający się stan.

Przykład:

```dart
class Counter extends StatefulWidget {
  const Counter({super.key});

  @override
  State<Counter> createState() => _CounterState();
}
```

Stan znajduje się w klasie:

```dart
class _CounterState extends State<Counter> {
  int counter = 0;

  void increment() {
    setState(() {
      counter++;
    });
  }
}
```

## setState()

`setState()` informuje Fluttera, że stan widgetu został zmieniony i interfejs powinien zostać ponownie zbudowany.

Przykład:

```dart
setState(() {
  counter++;
});
```

Możemy to zapamiętać:

```text
Zmiana danych
     ↓
setState()
     ↓
Flutter rebuild
     ↓
Nowy UI
```

## Flutter – wady

Trzeba nauczyć się języka Dart.

Aplikacje mogą mieć większy rozmiar niż niektóre aplikacje natywne.

Flutter nie zawsze zapewnia identyczne zachowanie jak natywne rozwiązania danej platformy.

Niektóre funkcje platformowe wymagają wykorzystania kodu natywnego.

Przy bardzo specyficznych funkcjach systemowych konieczna może być znajomość Kotlin/Java lub Swift/Objective-C.

## Flutter vs React Native

Flutter wykorzystuje:

```text
Dart
```

React Native wykorzystuje:

```text
JavaScript / TypeScript
```

Flutter posiada własny system widgetów.

React Native wykorzystuje komponenty i mechanizmy komunikacji z platformą natywną.

Można zapamiętać:

```text
Flutter
→ Dart
→ Widgety
→ Google

React Native
→ JavaScript / TypeScript
→ React
→ Meta
```

## Flutter vs Kotlin Multiplatform

Flutter wykorzystuje własny framework UI i język Dart.

Kotlin Multiplatform pozwala współdzielić kod napisany w Kotlinie pomiędzy platformami, jednocześnie umożliwiając korzystanie z natywnych mechanizmów platform.

Można to uprościć:

```text
Flutter
→ wspólny kod + Flutter UI

Kotlin Multiplatform
→ wspólny kod Kotlin + natywne UI lub współdzielone komponenty
```

**Widget Tree** – hierarchia widgetów.

**StatelessWidget** – widget bez własnego zmiennego stanu.

**StatefulWidget** – widget posiadający zmienny stan.

**setState()** – informuje Flutter o zmianie stanu.

**BuildContext** – kontekst widgetu w drzewie widgetów.

**MaterialApp** – podstawowa konfiguracja aplikacji Material.

**Scaffold** – podstawowa struktura ekranu.

**Navigator** – obsługa nawigacji pomiędzy ekranami.

**Provider / Riverpod / BLoC** – rozwiązania do zarządzania stanem.

**Future** – wartość dostępna w przyszłości.

**Stream** – strumień wielu wartości w czasie.

**pubspec.yaml** – plik konfiguracji projektu i zależności.

**pub.dev** – repozytorium pakietów Dart/Flutter.

**Hot Reload** – szybkie przeładowanie zmian w kodzie.

**DevTools** – narzędzia do debugowania i analizy aplikacji.

## Flutter – najważniejsze do zapamiętania

Flutter to framework firmy Google do tworzenia aplikacji wieloplatformowych.

Wykorzystuje język **Dart**.

Najważniejszym pojęciem we Flutterze jest **Widget**.

Interfejs aplikacji jest tworzony jako **Widget Tree**.

`StatelessWidget` jest używany dla widgetów bez zmiennego stanu.

`StatefulWidget` pozwala zarządzać zmieniającym się stanem.

`setState()` powoduje ponowne zbudowanie odpowiedniej części interfejsu.

`MaterialApp` definiuje podstawową konfigurację aplikacji.

`Scaffold` tworzy podstawową strukturę ekranu.

`Navigator` służy do przechodzenia między ekranami.

`Future` i `async/await` służą do obsługi operacji asynchronicznych.

`Provider`, `Riverpod` i `BLoC` pomagają zarządzać stanem.

`pubspec.yaml` przechowuje zależności projektu.

`Hot Reload` znacznie przyspiesza proces tworzenia aplikacji.

Flutter może komunikować się z REST API.

Flutter bardzo dobrze współpracuje z Firebase.

Flutter może być frontendem dla backendów napisanych między innymi w Spring Boot, ASP.NET Core, FastAPI czy Flask.

Najprościej zapamiętać:

```text
                         FLUTTER
                            ↓
                           DART
                            ↓
                         WIDGETS
                            ↓
                      WIDGET TREE
                            ↓
              ┌─────────────┼─────────────┐
              ↓             ↓             ↓
           Android         iOS          Desktop
              ↓             ↓             ↓
                            Web
                            ↓
                    REST API / Firebase
                            ↓
                         Backend
                            ↓
                         Database
```

**Flutter = Dart + Widgety + jedna baza kodu + wiele platform.**
