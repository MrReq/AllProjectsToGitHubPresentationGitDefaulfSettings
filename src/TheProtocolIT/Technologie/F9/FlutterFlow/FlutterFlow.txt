# FlutterFlow

## Czym jest FlutterFlow?

FlutterFlow to **wizualna platforma do tworzenia aplikacji**, która wykorzystuje technologię Flutter.

Pozwala tworzyć aplikacje za pomocą **interfejsu typu drag-and-drop**, bez konieczności ręcznego pisania całego kodu.

FlutterFlow jest przede wszystkim narzędziem **Low-Code**, ale pozwala również dodawać własny kod Dart i Flutter.

Dzięki temu można połączyć szybkość tworzenia aplikacji wizualnie z możliwością późniejszego rozszerzania projektu za pomocą kodu.

## Do czego służy FlutterFlow?

FlutterFlow można wykorzystywać do tworzenia:

aplikacji mobilnych.

aplikacji webowych.

MVP.

prototypów.

aplikacji biznesowych.

paneli administracyjnych.

aplikacji SaaS.

aplikacji e-commerce.

aplikacji wykorzystujących Firebase.

aplikacji wykorzystujących REST API.

aplikacji wykorzystujących AI.

## FlutterFlow a Flutter

Flutter i FlutterFlow nie są tym samym narzędziem.

**Flutter** jest frameworkiem programistycznym wykorzystującym język Dart.

**FlutterFlow** jest wizualnym środowiskiem Low-Code wykorzystującym Flutter jako podstawę technologiczną.

Można to zapamiętać:

```text
Flutter
→ framework
→ Dart
→ programowanie

FlutterFlow
→ platforma Low-Code
→ wizualne projektowanie
→ generowanie kodu Flutter
```

## Wady FlutterFlow

Nie wszystko można zrobić bez kodowania.

Bardziej zaawansowane aplikacje mogą wymagać Custom Code.

Trzeba rozumieć podstawy Fluttera, jeżeli projekt jest bardziej skomplikowany.

Automatycznie generowany kod nie zawsze będzie tak elegancki, jak ręcznie zaprojektowana aplikacja.

Przy bardzo specyficznych wymaganiach klasyczne programowanie Flutter może dawać większą kontrolę.

Platforma jest bardziej abstrakcyjna niż bezpośrednia praca w IDE.
