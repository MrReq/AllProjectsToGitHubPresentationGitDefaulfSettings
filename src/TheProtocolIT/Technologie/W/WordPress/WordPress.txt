# WordPress

## 1. Czym jest WordPress?

**WordPress** to jeden z najpopularniejszych systemów **CMS (Content Management System)**, czyli systemów zarządzania treścią.

Pozwala tworzyć i zarządzać:

- stronami internetowymi,
- blogami,
- sklepami internetowymi,
- portalami informacyjnymi,
- stronami firmowymi,
- portfolio,
- stronami edukacyjnymi,
- serwisami społecznościowymi.

WordPress został napisany głównie w **PHP** i korzysta z bazy danych, najczęściej **MySQL lub MariaDB**.

Podstawowa architektura wygląda następująco:

```text
Użytkownik
    ↓
Przeglądarka
    ↓
Serwer WWW
    ↓
WordPress
    ↓
PHP
    ↓
MySQL / MariaDB
```

WordPress może działać między innymi na:

```text
Linux
Apache
Nginx
PHP
MySQL / MariaDB
```


## 3. CMS

Najważniejszym pojęciem związanym z WordPressem jest **CMS**.

CMS pozwala zarządzać treścią poprzez panel administracyjny.

Zamiast pisać HTML:

```html
<h1>Moja firma</h1>
<p>Witamy na naszej stronie.</p>
```

możesz wejść do panelu:

```text
WordPress Admin
      ↓
Posts / Pages
      ↓
Edytor
      ↓
Publikuj
```

Treść jest następnie przechowywana w bazie danych.

## 4. WordPress.org vs WordPress.com

To bardzo ważne rozróżnienie.

### WordPress.org

Jest to oprogramowanie WordPress, które możesz pobrać i uruchomić na własnym hostingu.

Masz wtedy kontrolę nad:

- serwerem,
- bazą danych,
- PHP,
- motywami,
- pluginami,
- konfiguracją,
- domeną.

Schemat:

```text
Ty
 ↓
Hosting / VPS
 ↓
WordPress
 ↓
Twoja strona
```

### WordPress.com

Jest to platforma oferująca hosting WordPress.

Nie musisz samodzielnie konfigurować całego serwera.

Schemat:

```text
Ty
 ↓
WordPress.com
 ↓
Gotowa infrastruktura
 ↓
Twoja strona
```

Najprościej:

| WordPress.org | WordPress.com |
|---|---|
| Samodzielnie instalujesz | Usługa hostingowa |
| Większa kontrola | Większa prostota |
| Własny hosting | Hosting platformy |
| Więcej możliwości konfiguracji | Zależność od planu |
| Dla bardziej technicznych użytkowników | Dobry dla początkujących |

## 5. WordPress i PHP

WordPress jest oparty na **PHP**.

Przykładowa funkcja PHP:

```php
<?php

function hello_wordpress() {
    echo "Hello WordPress!";
}
```

PHP jest wykonywany po stronie serwera.

Schemat:

```text
Browser
   ↓
HTTP Request
   ↓
Web Server
   ↓
PHP
   ↓
WordPress
   ↓
Database
   ↓
HTML
   ↓
Browser
```

Użytkownik końcowy zazwyczaj otrzymuje już wygenerowany HTML.

## 15. WordPress REST API

WordPress posiada **REST API**, dzięki któremu inne aplikacje mogą komunikować się z WordPressem.

Przykładowo:

```text
Frontend
    ↓
REST API
    ↓

    ↓
Database
```

Przykładowo:

```http

```

```json
    "title": {

```

Dzięki temu WordPress może działać jako backend dla innego systemu.

## 16. Headless WordPress

**Headless WordPress** oznacza wykorzystanie WordPressa przede wszystkim jako backendu/CMS, podczas gdy frontend jest tworzony niezależnie.

W takim rozwiązaniu WordPress zarządza treścią, ale użytkownik może nie korzystać bezpośrednio z klasycznego frontendu WordPressa.

Można wtedy wykorzystać technologie takie jak:

```text

Vue

```

## 17. WordPress Hooks

Jedną z najważniejszych koncepcji programistycznych WordPressa są **Hooks**.

Dzielą się głównie na:

```text
Actions
Filters
```

### Action

Pozwala wykonać własny kod w określonym momencie.

```php
add_action('init', 'my_function');

function my_function() {
    // własny kod
}
```

### Filter

Pozwala zmienić dane przed ich wykorzystaniem.

```php
add_filter('the_title', 'modify_title');

function modify_title($title) {
    return $title . "!";
}
```

Dzięki hookom można rozszerzać WordPress bez modyfikowania jego głównego kodu.

## 18. Actions

Przykładowe zdarzenia:

```text
init
wp_enqueue_scripts
wp_footer
save_post
user_register
```

Możesz powiedzieć:

> „Kiedy użytkownik zostanie utworzony, wykonaj tę funkcję.”

```php
add_action('user_register', 'after_user_register');
```

## 19. Filters

Filtry pozwalają modyfikować dane.

Przykład:

```php
add_filter('the_content', 'add_text');

function add_text($content) {
    return $content . '<p>Dodano przez plugin.</p>';
}
```

WordPress przekazuje treść do funkcji, a funkcja zwraca zmodyfikowaną treść.

## 21. functions.php

W motywie często znajduje się:

```text
functions.php
```

Można tam umieszczać funkcje związane z motywem.

Przykład:

```php
<?php

function my_theme_setup() {
    add_theme_support('post-thumbnails');
}

add_action('after_setup_theme', 'my_theme_setup');
```

`functions.php` można traktować jako jeden z głównych punktów rozszerzania funkcjonalności motywu.

## 22. Shortcodes

WordPress posiada również **shortcodes**.

Przykład:

```text
[gallery]
```

Może zostać zamieniony przez WordPress na odpowiedni HTML.

Można również stworzyć własny shortcode:

```php
add_shortcode('hello', function () {
    return '<strong>Hello!</strong>';
});
```

Następnie:

```text
[hello]
```

może wygenerować:

```html
<strong>Hello!</strong>
```

## 34. WordPress Security

Bezpieczeństwo WordPressa jest bardzo ważne, ponieważ jest to bardzo popularna platforma.

Należy dbać o:

- aktualizacje WordPressa,
- aktualizacje pluginów,
- aktualizacje motywów,

## 45. WordPress vs własna aplikacja

| WordPress | Własna aplikacja |
|---|---|
| Gotowy CMS | Wszystko tworzysz sam |
| Szybki start | Dłuższy development |
| Dużo pluginów | Pełna kontrola |
| Duży ekosystem | Dowolna architektura |
| Dobry dla treści | Dobry dla niestandardowej logiki |
| PHP | Dowolna technologia |

Jeżeli potrzebujesz:

> „Strony firmowej z blogiem i formularzem”

WordPress może być świetnym rozwiązaniem.

Jeżeli potrzebujesz:

> „Bardzo złożonego systemu przetwarzającego dane i wykonującego specjalistyczne algorytmy”

często lepsza będzie własna aplikacja.

- dobra integracja z SEO,
- ogromna społeczność.

## 49. Wady WordPressa

WordPress ma również ograniczenia:

- pluginy mogą powodować konflikty,
- źle napisane pluginy mogą obniżać bezpieczeństwo,
- duża liczba pluginów może obciążać stronę,
- wymaga aktualizacji,
- konfiguracja dużych instalacji może być skomplikowana,
- nie jest najlepszym rozwiązaniem dla każdej aplikacji,
- PHP i architektura WordPressa mają swoją specyfikę.
