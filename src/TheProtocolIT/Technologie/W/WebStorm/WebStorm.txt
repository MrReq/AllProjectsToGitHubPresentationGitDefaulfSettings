# WebStorm

## 1. Czym jest WebStorm?

**WebStorm** to profesjonalne **IDE (Integrated Development Environment)** firmy **JetBrains**, przeznaczone przede wszystkim do tworzenia aplikacji webowych.

WebStorm koncentruje się przede wszystkim na:

- JavaScript,
- TypeScript,
- HTML,
- CSS,
- React,
- Angular,
- Vue,
- Node.js,
- aplikacjach frontendowych,
- aplikacjach full-stack.

WebStorm jest częścią ekosystemu IDE firmy JetBrains, podobnie jak **IntelliJ IDEA**, **PyCharm**, **CLion** czy **Rider**.

## 2. Do czego służy WebStorm?

WebStorm pozwala tworzyć kompletne aplikacje internetowe.

Możemy w nim pracować nad:

```text
Frontend
   ↓
JavaScript / TypeScript
   ↓
React / Vue / Angular
```

oraz:

```text
Backend
   ↓
Node.js
   ↓
Express / NestJS
```

Można więc wykorzystywać WebStorm zarówno do frontend developmentu, jak i części projektów full-stack.

## 3. WebStorm a JavaScript

Jednym z głównych zastosowań WebStorma jest programowanie w **JavaScript**.

Przykładowo:

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("Marcin"));
```

WebStorm zapewnia między innymi:

- autouzupełnianie,
- podpowiedzi metod,
- analizę kodu,
- wykrywanie błędów,
- refaktoryzację,
- debugging.

## 4. TypeScript

WebStorm posiada bardzo dobre wsparcie dla **TypeScript**.

Przykład:

```typescript
interface User {
    id: number;
    name: string;
}

const user: User = {
    id: 1,
    name: "Marcin"
};
```

IDE może analizować typy i informować o błędach jeszcze przed uruchomieniem aplikacji.

## 5. HTML

WebStorm posiada rozbudowane wsparcie dla HTML.

Przykład:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My Application</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>
```

IDE zapewnia:

- autouzupełnianie,
- walidację,
- nawigację,
- formatowanie,
- refaktoryzację,
- Emmet.

## 6. CSS

WebStorm obsługuje również CSS.

Przykład:

```css

    display: flex;
    justify-content: center;
    align-items: center;

```

```text

grid
margin

color
font-size
```

oraz wykrywać problemy w arkuszach stylów.

## 7. React

WebStorm posiada wsparcie dla **React**.

Przykładowy komponent:

```jsx
function Welcome({ name }) {
    return <h1>Hello, {name}!</h1>;
}

export default Welcome;
```

WebStorm może rozpoznawać:

- komponenty,
- props,
- JSX,
- hooki,
- importy,
- zależności pomiędzy komponentami.

## 8. Vue

WebStorm obsługuje również **Vue**.

Przykład:

```vue
<template>
    <h1>Hello World</h1>
</template>

<script>
export default {
    name: "App"
}
</script>
```

IDE może analizować strukturę komponentu Vue i zapewniać autouzupełnianie.

## 9. Angular

WebStorm może być również wykorzystywany do pracy z **Angular**.

Przykładowa architektura:

```text

   |
   +-- Components
   +-- Services
   +-- Modules
   +-- Templates
   +-- Routing
```

WebStorm pomaga w nawigowaniu pomiędzy tymi elementami projektu.

## 10. Node.js

WebStorm wspiera również **Node.js**.

Możemy tworzyć backend:

```javascript
const http = require("http");

const server = http.createServer((req, res) => {
    res.end("Hello World");
});

server.listen(3000);
```

WebStorm pozwala uruchamiać i debugować aplikacje Node.js bezpośrednio z IDE.

## 11. npm

WebStorm dobrze integruje się z **npm**.

Przykładowo możemy mieć:

```json
{
    "scripts": {
        "start": "node server.js",
        "build": "webpack",
        "test": "jest"
    }
}
```

WebStorm może rozpoznawać dostępne skrypty i pozwalać uruchamiać je z poziomu IDE.

## 12. package.json

Jednym z najważniejszych plików projektów JavaScript jest:

```text
package.json
```

Przykład:

```json
{
    "name": "my-app",
    "version": "1.0.0",
    "scripts": {
        "dev": "vite",
        "build": "vite build"
    },
    "dependencies": {
        "react": "^19.0.0"

}
```

WebStorm analizuje `package.json` i pomaga zarządzać zależnościami projektu.

## 13. Node Package Manager

WebStorm współpracuje z menedżerami pakietów, takimi jak:

```text

```

Możemy instalować biblioteki bezpośrednio z terminala:

```bash
npm install axios
```

lub korzystać z integracji dostępnych w IDE.

## 14. Debugger

Jedną z najważniejszych funkcji WebStorma jest **debugger**.

Możemy ustawić:

```text
Breakpoint
```

przy określonej linii kodu.

Przykład:

```javascript
function calculate(a, b) {
    const result = a + b; // breakpoint
    return result;
}
```

Podczas debugowania możemy obserwować:

- wartości zmiennych,
- stos wywołań,
- wykonanie kodu,
- warunki,
- przepływ programu.

## 15. Run Configurations

Pozwalają one określić, jak uruchomić aplikację.

Przykładowo:


Możemy stworzyć konfigurację:

```text

Node interpreter: Node.js

```

Następnie uruchamiamy aplikację przyciskiem **Run**.

## 19. Code Completion

Jedną z podstawowych funkcji WebStorma jest **autouzupełnianie kodu**.

Przykładowo wpisujemy:

```javascript
user.
```

WebStorm może zaproponować:

```text

email

```

Jest to szczególnie przydatne w dużych projektach.

## 20. Inspections

WebStorm analizuje kod podczas pisania.

Może wykrywać:

- błędy składni,
- niezdefiniowane zmienne,
- nieużywane importy,
- potencjalne problemy,
- błędne typy TypeScript,
- problemy z kodem.

Przykładowo:

```javascript
const name = "John";

console.log(username);
```

IDE może poinformować, że `username` nie zostało zdefiniowane.

## 21. Refactoring

WebStorm posiada rozbudowane możliwości **refaktoryzacji**.

Możemy między innymi:

- zmienić nazwę zmiennej,
- zmienić nazwę funkcji,
- przenieść kod,
- wydzielić funkcję,
- zmienić strukturę projektu.

Przykładowo:

```text
rename:
getUser()
    ↓
findUser()
```

IDE może automatycznie zmienić wszystkie odpowiednie odwołania.

## 22. Navigation

WebStorm pozwala szybko poruszać się po dużym projekcie.

Możemy przejść:

```text
Function → Definition
Component → Component File
Import → Module
Variable → Declaration
```

Dzięki temu praca z dużym projektem jest znacznie wygodniejsza.

## 23. Search Everywhere

Jedną z charakterystycznych funkcji IDE JetBrains jest **Search Everywhere**.

Pozwala szybko wyszukiwać:

- pliki,
- klasy,
- funkcje,
- akcje IDE,
- ustawienia,
- symbole.

Dzięki temu nie trzeba ręcznie przeszukiwać całego projektu.

## 24. Code Formatting

WebStorm może automatycznie formatować kod.

Przykładowo nieuporządkowany kod:

```javascript
function add(a,b){return a+b;}
```

może zostać sformatowany:

```javascript
function add(a, b) {
    return a + b;
}
```

Można również skonfigurować reguły formatowania projektu.

## 25. ESLint

WebStorm integruje się z **ESLint**.

ESLint służy do analizy kodu JavaScript i wykrywania potencjalnych problemów.

Przykładowy workflow:

```text
JavaScript
    ↓

    ↓
WebStorm
    ↓
Warnings / Errors
```

Dzięki temu można utrzymywać jednolity standard kodowania.

## 26. Prettier

WebStorm może również współpracować z **Prettierem**.

Można więc połączyć:

```text

+
Prettier
+
WebStorm
```

i uzyskać spójny styl kodu.

## 28. REST Client


## 38. Wady WebStorm

WebStorm również ma pewne wady.

Jest bardziej rozbudowany niż prosty edytor tekstu.

Może zużywać więcej pamięci RAM niż lekkie edytory.

Dla bardzo prostych projektów może być przesadnie rozbudowany.

Warto również pamiętać, że WebStorm jest produktem komercyjnym, choć JetBrains oferuje różne opcje licencjonowania i dostępności zależnie od sytuacji użytkownika.
