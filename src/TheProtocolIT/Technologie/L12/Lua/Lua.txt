Lua to lekki, szybki i elastyczny język programowania, który został zaprojektowany z myślą o łatwym osadzaniu w innych aplikacjach.

Jego nazwa pochodzi z języka portugalskiego i oznacza „Księżyc”.

Lua jest językiem skryptowym, który pozwala automatyzować działania, rozszerzać funkcjonalność programów oraz tworzyć logikę aplikacji.

Język został opracowany w 1993 roku na Papieskim Uniwersytecie Katolickim w Rio de Janeiro w Brazylii.

Lua jest znana z niewielkich wymagań dotyczących pamięci, prostej składni oraz łatwej integracji z językami takimi jak C i C++.

## 3. Najważniejsze cechy Lua

- Lekkość – interpreter Lua ma niewielkie wymagania sprzętowe.
- Prosta składnia – język jest stosunkowo łatwy do opanowania dla początkujących.
- Dynamiczne typowanie – typ zmiennej jest określany na podstawie przechowywanej wartości.
- Automatyczne zarządzanie pamięcią – Lua wykorzystuje mechanizm garbage collection.
- Wieloparadygmatowość – umożliwia programowanie proceduralne, funkcyjne oraz obiektowe realizowane za pomocą tabel i metatabel.
- Integracja z C i C++ – może być osadzana w aplikacjach napisanych w tych językach.
- Przenośność – działa na wielu systemach operacyjnych i platformach sprzętowych.
- Niewielki zestaw podstawowych typów danych – między innymi `nil`, `boolean`, `number`, `string`, `function`, `table` i `userdata`.

## 4. Jak wygląda kod w Lua?

Poniższy przykład pokazuje prosty program wyświetlający komunikat.

```
print("Hello, World!")
```

Do tworzenia zmiennych można używać słowa kluczowego `local`.

```
local name = "Adam"
local age = 25

print(name)
print(age)
```

Instrukcja warunkowa wygląda następująco:

```
local age = 20

if age >= 18 then
    print("Osoba pelnoletnia")
else
    print("Osoba niepelnoletnia")
end
```

Pętla `for` umożliwia powtarzanie instrukcji określoną liczbę razy.

```
for i = 1, 5 do
    print(i)
end
```

Funkcje definiuje się za pomocą słowa kluczowego `function`.

```
local function add(a, b)
    return a + b
end

print(add(10, 20))
```

W Lua bloki instrukcji zamyka się słowem `end`, a nie klamrami, jak w Javie czy C++.

## 5. Typy danych w Lua

| Typ        | Znaczenie                                                    |
| ---------- | ------------------------------------------------------------ |
| `nil`      | Brak wartości                                                |
| `boolean`  | Wartość logiczna `true` lub `false`                          |
| `number`   | Liczby                                                       |
| `string`   | Tekst                                                        |
| `function` | Funkcja                                                      |
| `table`    | Struktura danych używana między innymi jako tablica lub mapa |
| `userdata` | Dane zarządzane przez kod napisany w C                       |
| `thread`   | Wątek korutyny używany do współpracy między fragmentami kodu |

Szczególnie ważnym elementem Lua jest typ `table`.

Tabele mogą pełnić funkcję tablic, słowników, rekordów, a także podstawy do implementowania obiektów.

Przykład tabeli przechowującej dane użytkownika:

```
local user = {
    name = "Adam",
    age = 25,
    active = true
}

print(user.name)
print(user.age)
```

## 6. Programowanie obiektowe w Lua

Lua nie posiada tradycyjnych klas takich jak Java, C# czy C++.

Programowanie obiektowe można jednak realizować za pomocą tabel i metatabel.

Metatabele pozwalają definiować specjalne zachowania obiektów, na przykład sposób odczytywania pól lub wywoływania operatorów.

Przykład prostego obiektu:

```
local Person = {}
Person.__index = Person

function Person:new(name)
    local object = {
        name = name
    }

    setmetatable(object, Person)
    return object
end

function Person:greet()
    print("Czesc, " .. self.name)
end

local person = Person:new("Adam")
person:greet()
```

W tym przykładzie tabela `Person` pełni rolę wzorca obiektu, a metoda `greet()` wyświetla powitanie.

## 7. Najważniejsze narzędzia związane z Lua

- Lua Interpreter – interpreter umożliwiający wykonywanie skryptów Lua.
- LuaRocks – menedżer pakietów ułatwiający instalowanie bibliotek i modułów.
- ZeroBrane Studio – środowisko programistyczne przeznaczone do pracy z Lua.
- Visual Studio Code – edytor kodu, który można rozszerzyć o obsługę Lua.
- IntelliJ IDEA – środowisko, w którym obsługę Lua można uzyskać za pomocą odpowiednich wtyczek.
- OpenResty – platforma oparta na Nginx, umożliwiająca wykonywanie skryptów Lua w aplikacjach internetowych.

## 8. Zalety Lua

- Łatwy do przyswojenia język.
- Niewielkie zużycie pamięci.
- Dobra wydajność w zastosowaniach skryptowych.
- Możliwość osadzania w większych aplikacjach.
- Elastyczny system tabel i metatabel.
- Przydatność w grach i systemach wbudowanych.
- Dostępność bibliotek oraz narzędzi wspierających rozwój.

## 9. Wady Lua

- Mniejszy ekosystem niż w przypadku Pythona, JavaScriptu czy Javy.
- Mniej standardowych rozwiązań dla dużych aplikacji biznesowych.
- Dynamiczne typowanie może prowadzić do błędów wykrywanych dopiero podczas wykonywania programu.
- Programowanie obiektowe wymaga zastosowania wzorców opartych na tabelach i metatabelach.
- Popularność języka zależy w dużej mierze od konkretnej branży i platformy.

## 11. Jak rozpocząć naukę Lua?

Najlepiej zacząć od instalacji interpretera Lua i uruchamiania prostych skryptów z terminala.

Następnie warto opanować zmienne, typy danych, instrukcje warunkowe, pętle i funkcje.

Kolejnym krokiem powinno być poznanie tabel, metatabel, modułów oraz obsługi plików.

Na końcu warto stworzyć mały projekt, na przykład prostą grę tekstową, system ekwipunku albo zestaw skryptów automatyzujących wybrane zadania.

Materiały do nauki:

- Lua – [oficjalna strona języka](https://www.lua.org/).
- [oficjalna dokumentacja Lua 5.4](https://www.lua.org/manual/5.4/).
- [LuaRocks – menedżer pakietów](https://luarocks.org/).

## 12. Podsumowanie

Lua to lekki i elastyczny język programowania, szczególnie przydatny do tworzenia skryptów oraz rozszerzania funkcjonalności innych programów.

Jego największe atuty to prostota, małe wymagania i możliwość integracji z C oraz C++.

Warto go poznać przede wszystkim wtedy, gdy interesujesz się tworzeniem gier, automatyzacją, programowaniem systemów wbudowanych lub skryptowaniem w istniejących aplikacjach.
