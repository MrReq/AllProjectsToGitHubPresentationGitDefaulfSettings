# Java

## 1. Czym jest Java?

Java to obiektowy, wysokopoziomowy język programowania ogólnego przeznaczenia, rozwijany od lat 90. XX wieku.

Java została stworzona przez firmę Sun Microsystems, a obecnie jest rozwijana głównie przez Oracle oraz społeczność skupioną wokół OpenJDK.

Jedną z najważniejszych cech Javy jest zasada:

**„Write Once, Run Anywhere” (WORA)**

Oznacza to, że program skompilowany do kodu bajtowego może być uruchamiany na różnych systemach operacyjnych, jeśli posiadają odpowiednią maszynę wirtualną Java.

Java jest szeroko wykorzystywana w aplikacjach backendowych, systemach biznesowych, bankowości, aplikacjach webowych, systemach rozproszonych, mikroserwisach, Androidzie oraz narzędziach programistycznych.

## 3. JDK, JRE i JVM

To jedne z najważniejszych pojęć związanych z Javą.

### JVM – Java Virtual Machine

JVM jest maszyną wirtualną, która wykonuje kod bajtowy Javy.

Kod Java:

```text
plik .java
   ↓
kompilacja
   ↓
plik .class
   ↓
JVM
   ↓
wykonanie programu
```

JVM odpowiada między innymi za:

- wykonywanie bytecode,
- zarządzanie pamięcią,
- Garbage Collection,
- obsługę wyjątków,
- ładowanie klas,
- bezpieczeństwo wykonywania kodu.

### JRE – Java Runtime Environment

JRE zapewnia środowisko potrzebne do uruchamiania aplikacji Java.

W uproszczeniu:

```text
JRE = JVM + biblioteki potrzebne do uruchamiania programów
```

### JDK – Java Development Kit

JDK jest zestawem narzędzi przeznaczonych do tworzenia programów Java.

W uproszczeniu:

```text
JDK = JRE + narzędzia programistyczne
```

Przykładowe narzędzia JDK:

```text
javac
java
javadoc
jar
jdb
jlink
```

`javac` służy do kompilowania kodu Java.

Przykład:

```bash
javac Main.java
```

Uruchomienie:

```bash
java Main
```

## 4. Jak działa Java?

Przykładowy program:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Kod zapisujemy w pliku:

```text
Main.java
```

Następnie kompilujemy:

```bash
javac Main.java
```

Powstaje:

```text
Main.class
```

Plik `.class` zawiera **bytecode**.

Następnie JVM wykonuje bytecode:

```bash
java Main
```

Dzięki temu ten sam bytecode może być uruchomiony na różnych systemach operacyjnych posiadających kompatybilną JVM.

## 5. Garbage Collector

Java posiada automatyczne zarządzanie pamięcią.

Programista nie musi ręcznie zwalniać pamięci tak jak w języku C.

Za usuwanie nieużywanych obiektów odpowiada **Garbage Collector (GC)**.

Przykład:

```java
Person person = new Person();
person = null;
```

Jeżeli obiekt `Person` nie ma już żadnego odwołania, może zostać w przyszłości usunięty przez Garbage Collector.

## 6. Klasy i obiekty

Java jest silnie związana z programowaniem obiektowym.

Klasa definiuje strukturę i zachowanie obiektów.

```java
class Person {
    String name;
    int age;

    void sayHello() {
        System.out.println("Hello");
    }
}
```

Obiekt tworzymy za pomocą `new`:

```java
Person person = new Person();
```

Możemy ustawić wartości:

```java
person.name = "Jan";
person.age = 25;
```

I wywołać metodę:

```java
person.sayHello();
```

## 7. Enkapsulacja

Enkapsulacja polega na ukrywaniu wewnętrznego stanu obiektu i kontrolowaniu dostępu do niego.

Najczęściej wykorzystuje się:

```java
private
```

oraz metody:

```java
getter
setter
```

Przykład:

```java
class Person {

    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

## 8. Dziedziczenie

Java pozwala tworzyć klasy dziedziczące po innych klasach.

Służy do tego:

```java
extends
```

Przykład:

```java
class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}
```

`Dog` posiada również metodę odziedziczoną po `Animal`.

```java
Dog dog = new Dog();

dog.eat();
dog.bark();
```

## 9. Polimorfizm

Polimorfizm pozwala traktować różne obiekty poprzez wspólny typ.

```java
Animal animal = new Dog();
```

Pomimo że zmienna ma typ `Animal`, rzeczywistym obiektem jest `Dog`.

Polimorfizm jest jednym z najważniejszych mechanizmów programowania obiektowego.

## 10. Abstrakcja

Abstrakcja pozwala przedstawić najważniejsze elementy obiektu, ukrywając szczegóły implementacji.

Możemy wykorzystać:

```java
abstract
```

Przykład:

```java
abstract class Animal {

    abstract void makeSound();
}
```

Klasa dziedzicząca musi zaimplementować metodę:

```java
class Dog extends Animal {

    @Override
    void makeSound() {
        System.out.println("Woof");
    }
}
```

## 11. Interfejsy

Interfejs definiuje kontrakt, który może zostać zaimplementowany przez klasę.

Służy do tego:

```java
interface
```

Przykład:

```java
interface Flyable {
    void fly();
}
```

Implementacja:

```java
class Bird implements Flyable {

    @Override
    public void fly() {
        System.out.println("Flying");
    }
}
```

Jedna klasa może implementować wiele interfejsów:

```java
class Bird implements Flyable, Runnable {
}
```

Jest to szczególnie ważne, ponieważ Java nie pozwala na wielodziedziczenie klas.

## 12. Modyfikatory dostępu

Java posiada cztery poziomy dostępu:

```text
public
protected
default
private
```

### public

Dostęp praktycznie z każdego miejsca.

### protected

Dostęp w obrębie pakietu oraz klas dziedziczących.

### default

Brak jawnego modyfikatora.

Dostęp w obrębie tego samego pakietu.

### private

Dostęp tylko wewnątrz danej klasy.

## 20. Generics

Generyki pozwalają określić typ danych, które mogą być przechowywane w klasie lub kolekcji.

```java
List<String> names = new ArrayList<>();
```

Oznacza to, że lista przechowuje `String`.

Możemy tworzyć również własne klasy generyczne:

```java
class Box<T> {

    private T value;

    public T getValue() {
        return value;
    }

    public void setValue(T value) {
        this.value = value;
    }
}
```

## 21. Wyjątki

Java posiada mechanizm obsługi wyjątków.

Podstawowa konstrukcja:

```java
try {
    // kod
}
catch (Exception e) {
    // obsługa błędu
}
finally {
    // wykonywane na końcu
}
```

Przykład:

```java
try {
    int result = 10 / 0;
}
catch (ArithmeticException e) {
    System.out.println("Nie można dzielić przez zero");
}
```

Możemy również używać:

```java
throw
```

oraz:

```java
throws
```

## 24. Stream API

Stream API pozwala przetwarzać kolekcje w sposób deklaratywny.

Przykład:

```java
List<Integer> numbers = List.of(1, 2, 3, 4, 5);

List<Integer> result = numbers.stream()
        .filter(n -> n % 2 == 0)
        .map(n -> n * 2)
        .toList();
```

Tutaj:

```text
stream()
↓
filter()
↓
map()
↓
toList()
```

Stream API posiada między innymi:

```text
filter()
map()
flatMap()
sorted()
distinct()
limit()
skip()
forEach()
collect()
reduce()
count()
anyMatch()
allMatch()
noneMatch()
findFirst()
findAny()
```

## 30. JDBC

JDBC oznacza:

**Java Database Connectivity**

Jest to API pozwalające aplikacjom Java komunikować się z bazami danych.

Przykładowy schemat:

```text
Java
 ↓
JDBC
 ↓
JDBC Driver
 ↓
Database
```

Przykładowy kod:

```java

```

Następnie możemy wykonać zapytanie:

```java

        connection.prepareStatement(
            "SELECT * FROM users"
        );
```

JDBC jest często używane w aplikacjach backendowych.
