# JavaScript

## 1. Czym jest JavaScript?

JavaScript to wysokopoziomowy, dynamicznie typowany język programowania, który został stworzony przede wszystkim z myślą o tworzeniu interaktywnych stron internetowych.

Dzisiaj JavaScript jest znacznie bardziej uniwersalny.

Można go wykorzystywać do tworzenia:

- stron internetowych,
- aplikacji webowych,
- aplikacji backendowych,
- REST API,
- aplikacji desktopowych,
- aplikacji mobilnych,
- narzędzi CLI,
- aplikacji czasu rzeczywistego,
- serwerów,
- aplikacji wykorzystujących WebSocket,
- aplikacji wykorzystujących AI i Machine Learning.

JavaScript jest jednym z najważniejszych języków ekosystemu Web.

## 2. JavaScript a Java

Pomimo podobnej nazwy JavaScript i Java są różnymi językami.


Przykładowe silniki:


## 5. Podstawowa składnia

Najprostszy program:

```javascript
console.log("Hello World");
```

`console.log()` wyświetla informacje w konsoli.

Komentarz jednoliniowy:

```javascript
// komentarz
```

Komentarz wieloliniowy:

```javascript
/*
    komentarz
    wieloliniowy
*/
```

## 6. Zmienne

JavaScript posiada trzy podstawowe sposoby deklarowania zmiennych:

```javascript
var
let
const
```

Obecnie najczęściej wykorzystuje się:

```javascript
let
const
```

Przykład:

```javascript
let age = 25;
const name = "Marcin";
```

`const` oznacza, że zmiennej nie można ponownie przypisać.

```javascript
const age = 25;

// age = 30; // błąd
```

`let` pozwala na zmianę wartości:

```javascript
let age = 25;

age = 30;
```

`var` jest starszym sposobem deklarowania zmiennych i w nowoczesnym JavaScript zazwyczaj preferuje się `let` oraz `const`.

## 7. Typy danych

JavaScript jest **dynamicznie typowany**.

Oznacza to, że typ zmiennej nie musi być deklarowany podczas jej tworzenia.

```javascript
let value = 10;
```

Później:

```javascript
value = "Hello";
```

Podstawowe typy:

```text
string
number
bigint
boolean
undefined
null
symbol
object
```

## 8. String

Tekst można zapisać między innymi za pomocą:

```javascript
let name = "Marcin";
let city = 'Warszawa';
```

Można również używać template literals:

```javascript
let name = "Marcin";

console.log(`Hello ${name}`);
```

Template literals wykorzystują znak:

```text
`
```

i pozwalają łatwo wstawiać zmienne do tekstu.

## 9. Number

JavaScript wykorzystuje typ `number`.

```javascript

let price = 19.99;
```

Ten sam typ obsługuje liczby całkowite oraz zmiennoprzecinkowe.

JavaScript posiada również:

```javascript
Infinity
-Infinity
NaN
```

**Not a Number**

## 11. Null i Undefined

`undefined` oznacza zazwyczaj brak przypisanej wartości.

```javascript

```


`null` oznacza jawnie ustawiony brak wartości.

```javascript

```

## 12. Operatory

JavaScript posiada między innymi:

```text
+
-
*
/
%
**
```

Przykład:

```javascript
let result = 10 + 5;
```

Operatory porównania:

```text
==
===
!=
!==
>
<
>=
<=
```

Szczególnie ważny jest operator:

```javascript
===
```

który sprawdza zarówno wartość, jak i typ.

Przykład:

```javascript
5 === 5
```

daje:

```text
true
```

Natomiast:

```javascript

```

daje:

```text
false
```

## 13. Instrukcje warunkowe

Podstawowa konstrukcja:

```javascript
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Underage");
}
```

Możemy używać również:

```javascript
else if
```

Przykład:

```javascript
if (age >= 18) {
    console.log("Adult");
} else if (age >= 13) {
    console.log("Teenager");
} else {
    console.log("Child");
}
```



## 16. Pętle

JavaScript posiada kilka rodzajów pętli.

### for

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

### while

```javascript
while (condition) {
    // kod
}
```

### do...while

```javascript
do {
    // kod
} while (condition);
```

### for...of

Służy między innymi do iterowania po elementach tablic.

```javascript
for (const name of names) {
    console.log(name);
}
```

### for...in

Służy przede wszystkim do iterowania po właściwościach obiektu.

```javascript
for (const key in user) {
    console.log(key);
}
```

## 17. Funkcje

Funkcja to fragment kodu wykonujący określone zadanie.

```javascript
function add(a, b) {
    return a + b;
}
```

Wywołanie:

```javascript
let result = add(2, 3);
```

## 18. Arrow Functions

Nowoczesny JavaScript umożliwia stosowanie funkcji strzałkowych.

```javascript
const add = (a, b) => {
    return a + b;
};
```

Można zapisać krócej:

```javascript
const add = (a, b) => a + b;
```

Arrow functions są bardzo często używane w:

```text
map()
filter()
reduce()
forEach()
Promise
React
```

## 19. Tablice

Tablica może przechowywać wiele wartości.

```javascript
const numbers = [1, 2, 3, 4, 5];
```

Dostęp:

```javascript
numbers[0];
```

Długość:

```javascript
numbers.length;
```

Dodawanie:

```javascript
numbers.push(6);
```

Usuwanie ostatniego elementu:

```javascript
numbers.pop();
```

Dodawanie na początku:

```javascript
numbers.unshift(0);
```

Usuwanie pierwszego:

```javascript
numbers.shift();
```

Najważniejsze:

### map()

Tworzy nową tablicę na podstawie elementów.

```javascript
const numbers = [1, 2, 3];

const doubled = numbers.map(n => n * 2);
```

Rezultat:

```text
[2, 4, 6]
```

### filter()

Filtruje elementy.

```javascript
const numbers = [1, 2, 3, 4, 5];

const even = numbers.filter(n => n % 2 === 0);
```

Rezultat:

```text
[2, 4]
```

### reduce()

Pozwala sprowadzić wiele wartości do jednej.

```javascript
const numbers = [1, 2, 3, 4];

const sum = numbers.reduce(
    (total, n) => total + n,
    0
);
```

Rezultat:

```text
10
```

## 21. Obiekty

Obiekt przechowuje dane w postaci właściwości.

```javascript
const user = {
    name: "Marcin",
    age: 25,
    city: "Warszawa"
};
```

Dostęp:

```javascript
user.name;
```

lub:

```javascript
user["name"];
```

Możemy również przechowywać funkcje:

```javascript
const user = {
    name: "Marcin",

    sayHello() {
        console.log("Hello");
    }
};
```

## 22. Destructuring

Destructuring pozwala wygodnie wyciągać wartości.

```javascript
const user = {
    name: "Marcin",
    age: 25
};

const { name, age } = user;
```

Dla tablic:

```javascript
const numbers = [10, 20];

const [a, b] = numbers;
```

## 23. Spread Operator

Spread operator:

```text
...
```

Przykład:

```javascript
const numbers = [1, 2, 3];

const copy = [...numbers];
```

Możemy łączyć tablice:

```javascript
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];
```

Można go również wykorzystywać z obiektami:

```javascript
const user = {
    name: "Marcin",
    age: 25
};

const updatedUser = {
    ...user,
    age: 26
};
```

## 24. Rest Operator

Rest również wykorzystuje:

```text
...
```

ale pozwala zebrać wiele wartości.

```javascript
function sum(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}
```

Wywołanie:

```javascript
sum(1, 2, 3, 4);
```

## 25. Scope

JavaScript posiada zakresy zmiennych.

Najważniejsze pojęcia:

```text
global scope
function scope
block scope
```

`let` i `const` posiadają block scope.

```javascript
if (true) {
    let value = 10;
}

// value nie jest dostępne tutaj
```

## 26. Hoisting

JavaScript posiada mechanizm nazywany **hoistingiem**.

Deklaracje niektórych zmiennych i funkcji są przetwarzane przed wykonaniem kodu.

Ważne jest jednak rozróżnienie między:

```text
var
let
const
function
```

`let` i `const` znajdują się przed inicjalizacją w tzw. **Temporal Dead Zone**.

## 27. Closure

Closure jest jednym z bardzo ważnych pojęć JavaScript.

Funkcja może pamiętać zmienne z zakresu, w którym została utworzona.

```javascript
function counter() {

    let count = 0;

    return function () {
        count++;
        return count;
    };
}
```

Możemy następnie:

```javascript
const next = counter();

next();
next();
next();
```

Wyniki:

```text
1
2
3
```

## 28. this

`this` wskazuje na kontekst, w którym funkcja jest wykonywana.

Przykład:

```javascript
const user = {

    name: "Marcin",

    sayHello() {
        console.log(this.name);
    }
};
```

W przypadku arrow functions zachowanie `this` jest inne niż w klasycznych funkcjach.

Jest to jeden z ważniejszych tematów JavaScript.

## 29. Klasy

JavaScript posiada składnię klas.

```javascript
class Person {

    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    sayHello() {
        console.log(`Hello ${this.name}`);
    }
}
```

Tworzenie obiektu:

```javascript
const person = new Person("Marcin", 25);
```

## 30. Dziedziczenie

Klasy mogą dziedziczyć po innych klasach.

```javascript
class Animal {

    eat() {
        console.log("Eating");
    }
}

class Dog extends Animal {

    bark() {
        console.log("Barking");
    }
}
```

`Dog` posiada metodę `eat()` odziedziczoną po `Animal`.

## 31. Moduły

Nowoczesny JavaScript posiada system modułów.

Eksport:

```javascript
export function add(a, b) {
    return a + b;
}
```

Import:

```javascript
import { add } from "./math.js";
```

Możemy również stosować:

```javascript
export default
```

oraz:

```javascript
import something from "./file.js";
```

Moduły są podstawą organizowania większych aplikacji JavaScript.

- atrybuty,

## 34. Fetch API

JavaScript może komunikować się z serwerem.

Przykład:

```javascript
fetch("/api/users")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    });
```

Nowocześniejsza wersja z `async/await`:

```javascript
async function getUsers() {

    const response = await fetch("/api/users");

    const data = await response.json();

    console.log(data);
}
```

## 35. Promise

Promise może znajdować się w stanie:

```text

fulfilled
rejected
```

Przykład:

```javascript
const promise = new Promise((resolve, reject) => {

    resolve("Success");
});
```

Możemy wykorzystać:

```javascript

catch()
finally()
```

## 36. Async / Await

`async` i `await` upraszczają pracę z kodem asynchronicznym.

```javascript
async function getUser() {

    const response = await fetch("/api/user");

    const user = await response.json();

    return user;
}
```

Jest to obecnie jeden z najważniejszych sposobów obsługi operacji asynchronicznych w JavaScript.
