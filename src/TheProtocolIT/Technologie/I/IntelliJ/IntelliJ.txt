# IntelliJ IDEA – notatka

## 1. Czym jest IntelliJ IDEA?

IntelliJ IDEA to zintegrowane środowisko programistyczne (IDE – Integrated Development Environment) stworzone przez firmę JetBrains.

Program jest wykorzystywany przede wszystkim do tworzenia aplikacji w języku Java, ale obsługuje również inne technologie i języki, między innymi Kotlin, SQL, JavaScript oraz HTML i CSS w zależności od edycji i zainstalowanych wtyczek.

IntelliJ IDEA zapewnia narzędzia do pisania kodu, jego analizowania, kompilowania, uruchamiania, testowania i debugowania.

## 2. Do czego służy IntelliJ IDEA?

- Programowanie w Javie – tworzenie aplikacji konsolowych, desktopowych i serwerowych.
- Tworzenie aplikacji Spring Boot – budowanie backendów i usług REST API.
- Zarządzanie projektami – obsługa projektów Maven i Gradle.
- Debugowanie kodu – śledzenie wykonywania programu i analizowanie błędów.
- Testowanie oprogramowania – uruchamianie testów jednostkowych, na przykład JUnit.
- Obsługa baz danych – w odpowiednich edycjach korzystanie z narzędzi SQL i połączeń z bazami danych.
- Integracja z Git – zarządzanie zmianami w kodzie i współpraca z repozytoriami GitHub.
- Refaktoryzacja – bezpieczne zmienianie struktury kodu bez zamierzonej zmiany jego działania.

## 3. Najważniejsze funkcje IntelliJ IDEA

Inteligentne uzupełnianie kodu podpowiada nazwy klas, metod, zmiennych i dostępnych operacji.

Analiza kodu wykrywa potencjalne błędy, ostrzeżenia oraz problemy ze stylem programowania.

Refaktoryzacja umożliwia między innymi zmianę nazw klas i metod, przenoszenie elementów oraz wydzielanie metod.

Debugger pozwala ustawiać punkty przerwania (breakpoints), sprawdzać wartości zmiennych i analizować stos wywołań.

Integracja z Maven i Gradle ułatwia zarządzanie zależnościami oraz budowanie projektów.

Integracja z systemami kontroli wersji umożliwia wykonywanie operacji Git bezpośrednio w IDE.

Obsługa frameworków ułatwia pracę z technologiami takimi jak Spring Boot, zależnie od edycji, licencji i dostępnych wtyczek.

## 6. IntelliJ IDEA w praktyce – przykład Java

Załóżmy, że chcesz stworzyć prosty program wyświetlający komunikat w konsoli.

```
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, IntelliJ IDEA!");
    }
}
```

W IntelliJ IDEA możesz utworzyć klasę `Main`, wpisać kod, a następnie uruchomić metodę `main()` za pomocą przycisku uruchamiania.

W konsoli pojawi się wynik:

```
Hello, IntelliJ IDEA!
```

To samo środowisko pozwala później rozwijać projekt o kolejne klasy, testy jednostkowe, bazę danych i framework Spring Boot.

## 7. Najważniejsze skróty klawiszowe

| Skrót              | Działanie                                           |
| ------------------ | --------------------------------------------------- |
| `Shift` dwa razy   | Wyszukiwanie plików, klas, akcji i ustawień         |
| `Ctrl + Space`     | Podstawowe uzupełnianie kodu                        |
| `Alt + Enter`      | Szybkie poprawki i podpowiedzi                      |
| `Shift + F10`      | Uruchomienie ostatniej konfiguracji                 |
| `Shift + F9`       | Uruchomienie debugowania                            |
| `Ctrl + Alt + L`   | Formatowanie kodu                                   |
| `Ctrl + /`         | Komentowanie lub odkomentowanie linii               |
| `Ctrl + Shift + F` | Wyszukiwanie tekstu w projekcie                     |
| `Alt + Insert`     | Generowanie kodu, na przykład konstruktorów i metod |

Skróty mogą się różnić w zależności od systemu operacyjnego i konfiguracji mapowania klawiszy.

## 8. Zalety i wady IntelliJ IDEA

Zalety:

- Rozbudowane wsparcie dla języka Java.
- Inteligentne podpowiedzi i analiza kodu.
- Wygodne debugowanie i refaktoryzacja.
- Integracja z Maven, Gradle, Git i JUnit.
- Dobre wsparcie dla aplikacji Spring Boot w edycji Ultimate.
- Możliwość rozszerzania funkcjonalności za pomocą wtyczek.

Wady:

- Może zużywać dużo pamięci RAM przy dużych projektach.
- Niektóre zaawansowane funkcje wymagają płatnej edycji.
- Duża liczba funkcji może być początkowo przytłaczająca dla początkujących.
- Indeksowanie dużych projektów może zajmować czas.

## 10. Co warto zapamiętać?

IntelliJ IDEA to jedno z najważniejszych środowisk programistycznych wykorzystywanych w ekosystemie Javy.

Umożliwia pisanie, uruchamianie, testowanie, debugowanie i refaktoryzację kodu w jednym miejscu.

Jest szczególnie przydatne podczas nauki Javy, pracy z Mavenem, tworzenia testów JUnit oraz budowania aplikacji backendowych w Spring Boot.
