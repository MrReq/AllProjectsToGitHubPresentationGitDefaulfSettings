# C++ — notatka o technologii

## 1. Czym jest C++?

C++ to język programowania ogólnego przeznaczenia, który wywodzi się z języka C i został rozwinięty przez Bjarne Stroustrupa.

Język C++ łączy programowanie proceduralne, obiektowe, generyczne oraz elementy programowania funkcyjnego.

Jest znany z wysokiej wydajności, dużej kontroli nad pamięcią i możliwości tworzenia zarówno niewielkich programów, jak i rozbudowanych systemów.

C++ jest językiem kompilowanym, co oznacza, że kod źródłowy jest przekształcany przez kompilator do kodu maszynowego lub innej postaci wykonywalnej.

Obecnie język jest rozwijany przez standardy ISO, takie jak C++17, C++20, C++23 oraz C++26.

## 2. Najważniejsze cechy C++

Wydajność

C++ umożliwia tworzenie aplikacji, które wykonują operacje bardzo szybko i efektywnie wykorzystują zasoby komputera.

Programowanie obiektowe

Pozwala tworzyć klasy i obiekty, wykorzystywać dziedziczenie, enkapsulację oraz polimorfizm.

Kontrola nad pamięcią

Programista może zarządzać pamięcią niskopoziomowo, ale może też korzystać z inteligentnych wskaźników i automatycznego zarządzania zasobami.

Programowanie generyczne

Szablony (templates) pozwalają pisać kod, który działa z różnymi typami danych.

Biblioteka standardowa

C++ oferuje między innymi kontenery, algorytmy, obsługę tekstu, plików, wątków i czasu.

Wieloparadygmatowość

Język pozwala stosować różne style programowania w zależności od problemu.

## 3. Jak działa C++?

Typowy proces tworzenia aplikacji w C++ składa się z kilku etapów.

1. Programista zapisuje kod źródłowy, najczęściej w plikach `.cpp` i `.h` lub `.hpp`.
2. Preprocesor przetwarza dyrektywy, takie jak `#include` i `#define`.
3. Kompilator sprawdza kod i przekształca go do kodu obiektowego.
4. Linker łączy pliki obiektowe i biblioteki w program wykonywalny.
5. System operacyjny uruchamia gotową aplikację.

Do najpopularniejszych kompilatorów należą GCC, Clang oraz MSVC.

## 4. Podstawowy przykład programu

Poniższy program wyświetla komunikat, definiuje zmienną i wykonuje proste obliczenie.

```
#include <iostream>

int main() {
    int a = 10;
    int b = 20;

    int suma = a + b;

    std::cout << "Witaj w C++!" << '\n';
    std::cout << "Suma: " << suma << '\n';

    return 0;
}
```

`#include <iostream>` udostępnia podstawowe mechanizmy wejścia i wyjścia.

`int main()` jest funkcją, od której rozpoczyna się wykonywanie programu.

`int` oznacza typ danych przeznaczony do przechowywania liczb całkowitych.

`std::cout` służy do wyświetlania danych w konsoli.

`return 0` oznacza, że program zakończył się poprawnie.

## 5. Programowanie obiektowe w C++

C++ umożliwia modelowanie rzeczywistych obiektów za pomocą klas.

Przykładem może być klasa reprezentująca samochód.

```
#include <iostream>
#include <string>

class Samochod {
private:
    std::string marka;
    int predkosc;

public:
    Samochod(const std::string& marka)
        : marka(marka), predkosc(0) {}

    void przyspiesz(int wartosc) {
        predkosc += wartosc;
    }

    void pokazInformacje() const {
        std::cout << marka
                  << ", predkosc: "
                  << predkosc << '\n';
    }
};

int main() {
    Samochod auto1("Toyota");

    auto1.przyspiesz(50);
    auto1.pokazInformacje();

    return 0;
}
```

Klasa `Samochod` opisuje właściwości i zachowanie samochodu.

Pola `marka` i `predkosc` są prywatne, dlatego nie można bezpośrednio modyfikować ich z zewnątrz klasy.

Konstruktor inicjalizuje obiekt podczas jego tworzenia.

Metoda `przyspiesz()` zmienia prędkość, a `pokazInformacje()` wyświetla dane.

## 7. STL — Standard Template Library

STL to część biblioteki standardowej C++, która udostępnia gotowe struktury danych oraz algorytmy.

Najważniejsze kontenery to:

- `std::vector` — dynamiczna tablica.
- `std::array` — tablica o stałym rozmiarze.
- `std::list` — lista dwukierunkowa.
- `std::map` — kolekcja par klucz-wartość uporządkowana według kluczy.
- `std::unordered_map` — mapa oparta na tablicy haszującej.
- `std::set` — zbiór unikalnych elementów.
- `std::queue` — kolejka FIFO.
- `std::stack` — stos LIFO.

Przykład wykorzystania `std::vector`:

```
#include <iostream>
#include <vector>

int main() {
    std::vector<int> liczby = {10, 20, 30};

    liczby.push_back(40);

    for (int liczba : liczby) {
        std::cout << liczba << '\n';
    }

    return 0;
}
```

Biblioteka STL pozwala ograniczyć ilość własnego kodu i korzystać ze sprawdzonych implementacji.

## 8. Zarządzanie pamięcią

C++ daje dużą kontrolę nad pamięcią, co jest jedną z jego zalet, ale także źródłem potencjalnych błędów.

W starszym stylu programowania często korzystano z `new` i `delete`, które wymagają ręcznego zarządzania pamięcią.

W nowoczesnym C++ zaleca się przede wszystkim stosowanie obiektów automatycznych, kontenerów standardowych i inteligentnych wskaźników.

Najważniejsze inteligentne wskaźniki to:

- `std::unique_ptr` — wyłączna własność obiektu.
- `std::shared_ptr` — współdzielona własność obiektu.
- `std::weak_ptr` — nieposiadająca referencja do obiektu zarządzanego przez `shared_ptr`.

Technika RAII wiąże czas życia zasobu z czasem życia obiektu, co pomaga automatycznie zwalniać pamięć i inne zasoby.

## 11. Zalety i wady C++

Zalety:

- Wysoka wydajność i efektywne wykorzystanie zasobów.
- Duża kontrola nad pamięcią i sprzętem.
- Możliwość tworzenia aplikacji wieloplatformowych.
- Bogata biblioteka standardowa i rozbudowany ekosystem narzędzi.
- Przydatność w projektach wymagających małych opóźnień.

Wady:

- Stosunkowo wysoki próg wejścia dla początkujących.
- Złożona składnia i wiele zaawansowanych mechanizmów.
- Nieprawidłowe zarządzanie pamięcią może prowadzić do trudnych błędów.
- Konfiguracja kompilacji i zależności bywa bardziej wymagająca niż w niektórych językach wysokiego poziomu.
- Ręczna optymalizacja nie zawsze jest konieczna, a przedwczesna może utrudniać rozwój projektu.

## 13. Jak zacząć naukę C++?

Proponowana kolejność nauki:

1. Zmienne, typy danych, operatory i instrukcje warunkowe.
2. Pętle, funkcje i obsługa wejścia oraz wyjścia.
3. Tablice, `std::string` i `std::vector`.
4. Klasy, obiekty, konstruktory i enkapsulacja.
5. Wskaźniki, referencje i zarządzanie pamięcią.
6. STL, algorytmy i szablony.
7. Wyjątki, pliki, biblioteki i obsługa błędów.
8. RAII, smart pointers, nowoczesny C++ i podstawy współbieżności.
9. Git, CMake, testy jednostkowe i debugowanie.
10. Projekt praktyczny, np. menedżer zadań, aplikacja konsolowa lub aplikacja GUI w Qt.

## 14. Czy warto uczyć się C++?

Tak, szczególnie jeśli interesuje Cię programowanie systemowe, tworzenie gier, robotyka, aplikacje desktopowe albo wydajne przetwarzanie danych.

C++ pomaga zrozumieć działanie pamięci, kompilacji, struktur danych i wydajności programów.

Jeżeli Twoim głównym celem jest rozwój w backendzie Java i Spring Boot, C++ będzie wartościowym uzupełnieniem wiedzy, ale nie musi mieć pierwszeństwa przed SQL, testami, Git i architekturą aplikacji.

Najlepszym sposobem nauki jest połączenie teorii z regularnym pisaniem kodu oraz budowaniem małych projektów.
