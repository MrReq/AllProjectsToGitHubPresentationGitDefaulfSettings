C# (czyt. C Sharp) to nowoczesny, obiektowy język programowania opracowany przez firmę Microsoft, który jest częścią ekosystemu .NET.

C# został zaprojektowany z myślą o tworzeniu bezpiecznych, czytelnych i wydajnych aplikacji.

Język jest wykorzystywany do tworzenia aplikacji internetowych, programów desktopowych, gier komputerowych, aplikacji mobilnych, usług backendowych oraz systemów biznesowych.

C# korzysta z platformy .NET, która dostarcza środowisko uruchomieniowe, biblioteki standardowe i narzędzia programistyczne.

Kod C# jest zazwyczaj kompilowany do języka pośredniego CIL, a następnie wykonywany przez środowisko uruchomieniowe .NET, które wykorzystuje między innymi kompilację JIT.

## 2. Najważniejsze cechy C\#

Programowanie obiektowe

C# obsługuje klasy, obiekty, dziedziczenie, enkapsulację, abstrakcję i polimorfizm.

Statyczne typowanie

Typy zmiennych są sprawdzane podczas kompilacji, co pomaga wykrywać wiele błędów przed uruchomieniem programu.

Automatyczne zarządzanie pamięcią

Środowisko .NET wykorzystuje Garbage Collector, który automatycznie odzyskuje pamięć zajmowaną przez nieużywane obiekty.

Asynchroniczność

Słowa kluczowe `async` i `await` ułatwiają pisanie kodu obsługującego operacje wejścia i wyjścia, np. zapytania HTTP lub operacje bazodanowe.

LINQ

Language Integrated Query pozwala wygodnie filtrować, sortować i przekształcać dane w kolekcjach oraz innych źródłach danych.

Wieloplatformowość

Współczesny .NET pozwala uruchamiać aplikacje C# na Windows, Linux i macOS, zależnie od użytych bibliotek i funkcji.

## 3. Jak działa C#?

Typowy proces tworzenia aplikacji w C# wygląda następująco:

1. Programista zapisuje kod źródłowy w plikach `.cs`.
2. Kompilator C# przekształca kod do postaci pośredniej CIL.
3. Środowisko uruchomieniowe .NET ładuje program i jego zależności.
4. Kod jest wykonywany, często z wykorzystaniem kompilacji JIT do kodu maszynowego.
5. Garbage Collector zarządza pamięcią obiektów, a biblioteki .NET udostępniają gotowe funkcje.

W ekosystemie .NET można także tworzyć aplikacje publikowane w trybie AOT, w którym część lub całość kodu jest kompilowana do kodu maszynowego przed uruchomieniem.

## 4. Podstawowy przykład programu

```
using System;

class Program
{
    static void Main()
    {
        string imie = "Jan";
        int wiek = 25;

        Console.WriteLine($"Cześć, {imie}!");
        Console.WriteLine($"Masz {wiek} lat.");
    }
}
```

`using System` udostępnia między innymi klasę `Console`.

`class Program` definiuje klasę programu.

`static void Main()` jest tradycyjnym punktem wejścia aplikacji konsolowej.

`string` przechowuje tekst, a `int` liczby całkowite.

`Console.WriteLine()` wyświetla tekst w konsoli.

Interpolacja `$"..."` pozwala wstawiać wartości zmiennych bezpośrednio do tekstu.

## 5. Programowanie obiektowe w C\#

C# jest często wykorzystywany w projektach opartych na programowaniu obiektowym.

Przykładem może być klasa reprezentująca konto bankowe.

```
using System;

class KontoBankowe
{
    public string Wlasciciel { get; }

    private decimal saldo;

    public KontoBankowe(string wlasciciel)
    {
        Wlasciciel = wlasciciel;
        saldo = 0m;
    }

    public void Wplac(decimal kwota)
    {
        if (kwota <= 0)
            throw new ArgumentException("Kwota musi być dodatnia.");

        saldo += kwota;
    }

    public decimal PobierzSaldo()
    {
        return saldo;
    }
}

class Program
{
    static void Main()
    {
        KontoBankowe konto = new KontoBankowe("Jan");

        konto.Wplac(500m);

        Console.WriteLine(konto.PobierzSaldo());
    }
}
```

Klasa `KontoBankowe` opisuje dane i zachowania konta.

Konstruktor inicjalizuje obiekt podczas jego tworzenia.

Pole `saldo` jest prywatne, dzięki czemu można kontrolować sposób jego modyfikowania.

Metoda `Wplac()` sprawdza poprawność kwoty przed zmianą salda.

Typ `decimal` jest często wykorzystywany do reprezentowania wartości pieniężnych.

## 7. .NET — platforma dla C\#

.NET to platforma programistyczna, na której działa większość współczesnych aplikacji C#.

W jej skład wchodzą środowisko uruchomieniowe, kompilatory, biblioteki oraz narzędzia do budowania i testowania programów.

Najważniejsze technologie ekosystemu .NET to:

- ASP.NET Core — tworzenie API, aplikacji internetowych i backendów.
- Entity Framework Core — mapowanie obiektowo-relacyjne i obsługa baz danych.
- Windows Forms — tworzenie aplikacji desktopowych dla Windows.
- WPF — tworzenie rozbudowanych aplikacji okienkowych dla Windows.
- .NET MAUI — budowanie aplikacji na obsługiwane platformy mobilne i desktopowe.
- Blazor — tworzenie interfejsów internetowych z wykorzystaniem C#.
- SignalR — komunikacja w czasie rzeczywistym.
- xUnit, NUnit i MSTest — testowanie jednostkowe.

Ważne jest rozróżnienie: C# to język programowania, natomiast .NET to platforma, na której można uruchamiać programy napisane między innymi w C#.

| Cecha                | C#                       | Java                             | C++                                                              |

C# i Java są do siebie podobne pod względem składni oraz podejścia obiektowego.

C++ zapewnia większą kontrolę nad pamięcią i zasobami, ale wymaga również większej uwagi przy zarządzaniu nimi.

## 11. Zalety i wady C\#

Zalety:

- Czytelna składnia i rozbudowane możliwości programowania obiektowego.
- Bogaty ekosystem bibliotek i narzędzi .NET.
- Automatyczne zarządzanie pamięcią.
- Wygodne tworzenie API i aplikacji backendowych.
- Dobre wsparcie asynchroniczności i testowania.
- Możliwość tworzenia aplikacji dla wielu platform.

Wady:

- Niektóre technologie, takie jak WPF i Windows Forms, są przeznaczone przede wszystkim dla Windows.
- Garbage Collector nie eliminuje wszystkich problemów związanych z pamięcią i zasobami.
- Wydajność i zużycie pamięci zależą od sposobu implementacji oraz rodzaju aplikacji.
- Ekosystem .NET ma wiele bibliotek i technologii, których poznanie wymaga czasu.
- Przy tworzeniu aplikacji mobilnych i desktopowych trzeba uwzględnić ograniczenia konkretnych platform.

## 13. Czy warto uczyć się C#?

Tak, szczególnie jeśli interesuje Cię backend, aplikacje biznesowe, tworzenie gier w Unity albo rozwój oprogramowania w środowisku Microsoft.

Jeśli znasz już podstawy Javy, wiele zagadnień C# będzie Ci znajomych, dzięki czemu możesz szybciej przejść do nauki platformy .NET i ASP.NET Core.

C# jest również dobrym wyborem do budowania REST API, aplikacji połączonych z bazą danych oraz projektów wymagających testowania i dobrej organizacji kodu.
